# 🚀 Ventrix CRM - Full Stack Web Development Task

**"I built this system to manage real clients."**

A production-ready, single-file CRM dashboard with enterprise-grade features, beautiful glassmorphism UI, and full CRUD functionality. Perfect for sales teams managing high-value B2B leads.

## ✨ Features

### **Core CRM Functionality**
- ✅ **Full CRUD Operations** - Create, Read, Update, Delete leads
- ✅ **30+ Realistic Demo Leads** - $5M+ pipeline with companies like TechFlow, HealthPlus, FinTech
- ✅ **Pipeline Analytics** - Total value, average deal size, close rate, notes tracking
- ✅ **Advanced Search** - Filter by name, company, email, or source
- ✅ **Smart Sorting** - Sort by value, name, company, or source (desc/asc)
- ✅ **Status Pipeline** - New → Contacted → Qualified → Proposal → Closed (one-click progression)

### **Enterprise Features**
- 🎨 **Glassmorphism UI** - Modern backdrop-blur design with gradients & animations
- 📱 **Fully Responsive** - Works on desktop, tablet, mobile
- 💾 **Persistent Storage** - LocalStorage saves all data (persists across sessions)
- 📝 **Notes System** - Add, view, delete unlimited notes per lead with timestamps
- 🔐 **Secure Login** - Demo: `admin@ventrix.com` / `password`
- ⚡ **Loading States** - Smooth UX with spinners and feedback
- 🎯 **Production Polish** - Hover effects, keyboard navigation, error handling
